# マイ・フォントブック

Windows などにインストール済みのフォントをドラッグ&ドロップで読み込み、一覧・分類・比較・プレビューできる、単一HTMLのフォントブックです。

## 使い方
1. `index.html` をブラウザで開く（または GitHub Pages の URL を開く）
2. `C:\Windows\Fonts` で Ctrl+A → ページにドラッグ&ドロップ
3. 読み込んだフォントと設定（お気に入り・リスト・タグ）はブラウザに自動保存されます

## 主な機能
- TTF / OTF / TTC / OTC / WOFF / WOFF2 対応、フォルダごとのドロップも可
- カテゴリ自動分類、メーカー識別・メーカー順の並び替え
- ファミリー枠表示と一斉の展開・折り畳み
- 自作リスト・タグ、比較表示、組み合わせ提案、色・字間・行間の調整
- 設定のバックアップ(JSON)と復元、CSV出力、印刷/PDF

## プライバシー
フォントファイルはブラウザ内でのみ処理され、外部へ送信されません。

## 注意
フォントファイルはライセンス上、このリポジトリへアップロードしないでください。
